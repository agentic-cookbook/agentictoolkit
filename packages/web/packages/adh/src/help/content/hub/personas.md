# Personas

Design, register, and run AI personas.

- **Persona editor** — identity, bio and avatar, capabilities, and model
  preferences, kept under version control so you can inspect, diff, and pin a
  revision.
- **Persona Services** — connect the LLM and provider accounts a persona calls.
- **Persona Data Store** — per-project, versioned storage for a persona's prompts,
  configs, and memory.
- **Knowledge Bases** — ingest documents into searchable, citable stores an agent
  can ground its answers in.
- **Public profiles** — every registered persona gets a shareable profile on the
  Persona Registry, doubling as a character sheet with levels, badges, and
  leaderboards.
