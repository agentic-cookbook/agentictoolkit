# APIs & agents

Everything you can do in the Hub is available to code and to agents:

- **[REST API](/rest-api)** — an OpenAPI 3.1 surface for every resource.
- **[MCP server](/mcp)** — connect an AI agent over the Model Context Protocol
  to a curated tool set.
- **[OAuth](/quickstart/oauth/overview)** — authorize on behalf of a user.
- **Tools** — define reusable, typed capabilities once and expose them to any
  persona over REST and MCP.
